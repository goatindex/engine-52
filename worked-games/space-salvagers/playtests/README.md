# Playtest reports

One file per session, named `YYYY-MM-DD-<short-slug>.md`. Each report should state:

- date, player count, the group's experience with the register
- which rules were misread or disputed at the table
- the watch-list observations from the Minimum Prototype's "What this prototype tests" table
- the three numbers that felt most wrong
- which Pattern Language version the session was played against

Reports here are the evidence that moves stars in the Pattern Language (Appendix B protocol).
